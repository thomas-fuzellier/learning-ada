# Learning Ada

A step-by-step journey through Ada 2022 and SPARK, from a first program to real-time and formally verified code.

Each lesson is a standalone [Alire](https://alire.ada.dev) project, built with zero warnings and GNAT style checks enforced as errors.

## Build and run a lesson

```sh
cd lesson_01
alr build
alr run
```
